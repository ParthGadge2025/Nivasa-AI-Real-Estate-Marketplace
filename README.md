# 🏠 Nivasa AI — Smart Real-Estate Marketplace

A modern, responsive and **100% free frontend real-estate marketplace** built with HTML, CSS and JavaScript.

> Explore properties · AI-style matching · EMI calculator · visit calendar · voice search · 5-language UI · dark/light mode

## ✨ Features

- 🏡 Property discovery with realistic demo listings
- 🔎 Search by city, locality, property and purpose
- 🧠 AI-style property matching without a paid API
- 🤖 Nivasa AI assistant with useful property/EMI responses
- 💰 Home-loan EMI calculator with live calculations
- 📊 Affordability snapshot
- 📅 Property-visit calendar with local event storage
- 🎙️ Browser voice search using Web Speech API
- 🌍 English, Hindi, Marathi, Malayalam and Tamil UI labels
- ❤️ Wishlist saved in browser LocalStorage
- 🌙 Dark/light theme saved locally
- 📱 Responsive mobile/tablet/desktop UI
- ✨ Glassmorphism, gradients, hover effects and reveal animations
- ⚡ No backend, database, API key or paid service required

## 🚀 Run locally

The current AI assistant is intentionally implemented with local JavaScript logic so the project remains **free, private and API-key-free**.

For a production version, you can connect the assistant to an AI API or your own backend. Never expose private API keys in frontend code.

## 💰 EMI calculator

The calculator uses the standard reducing-balance EMI formula:

`EMI = P × r × (1+r)^n / ((1+r)^n - 1)`

where:

- `P` = loan principal
- `r` = monthly interest rate
- `n` = number of monthly payments

The calculator is for planning/demo purposes and does not represent a bank offer.
